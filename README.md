# Football Alert Bot

Бот надсилає сповіщення в Telegram коли:
- В 1-му таймі було 2+ голи
- Загальна кількість голів 5+ до 80-ї хвилини

## Файли
- `bot.py` — основний скрипт
- `requirements.txt` — залежності
- `Procfile` — для Railway
- `railway.toml` — конфіг Railway

## Деплой на Railway
1. Завантаж всі файли на GitHub
2. Підключи репозиторій на railway.app
3. Railway автоматично запустить бота
